# Solution

Throughout, the coset $q + \mathbb{Z}$ is the neutral element of
$\mathbb{Q}/\mathbb{Z}$ precisely when $q \in \mathbb{Z}$. Adding a coset
to itself $k$ times gives $k q + \mathbb{Z}$, so:

> the order of $q + \mathbb{Z}$ is the least $k \geq 1$ with
> $kq \in \mathbb{Z}$ (and infinite if no such $k$ exists).

**(a)** Let $q = a/b$ in lowest terms, $b \geq 1$. First,
$b q = a \in \mathbb{Z}$, so the order is finite and at most $b$.
Conversely, suppose $kq = ka/b \in \mathbb{Z}$ for
some $k \geq 1$. Then $b \mid ka$, and since $\gcd(a, b) = 1$, Euclid's
lemma gives $b \mid k$. The least positive $k$ divisible by $b$ is $b$
itself, so the order of $q + \mathbb{Z}$ is exactly $b$.

**(b)** *Infinite:* the elements $\tfrac{1}{2} + \mathbb{Z},
\tfrac{1}{3} + \mathbb{Z}, \tfrac{1}{4} + \mathbb{Z}, \dots$ have orders
$2, 3, 4, \dots$ by part (a), hence are pairwise distinct — a group whose
elements realize infinitely many distinct orders is infinite.

*Torsion:* every element of $\mathbb{Q}/\mathbb{Z}$ is of the form
$a/b + \mathbb{Z}$ with the fraction in lowest terms, and by (a) its order
is the reduced denominator $b$ — a finite number. So every element has
finite order.

*Not cyclic:* if $g$ generated $\mathbb{Q}/\mathbb{Z}$, then $g$ would have
some finite order $b$, and the cyclic group $\langle g \rangle =
\{e, g, 2g, \dots, (b-1)g\}$ would have at most $b$ elements — but
$\mathbb{Q}/\mathbb{Z}$ is infinite. Contradiction.

**(c)** By (a) the element $\tfrac{1}{n} + \mathbb{Z}$ has order $n$, so
its cyclic group consists of the $n$ distinct multiples
$$k \left( \tfrac{1}{n} + \mathbb{Z} \right) = \tfrac{k}{n} + \mathbb{Z},
\qquad k = 0, 1, \dots, n - 1,$$
which is exactly the claimed set, and $|H_n| = n$.

If $m \mid n$, write $n = md$. Then
$\tfrac{1}{m} + \mathbb{Z} = \tfrac{d}{n} + \mathbb{Z} \in H_n$, so the
whole cyclic group $H_m$ generated by it lies in $H_n$.

**(d)** Let $H \leq \mathbb{Q}/\mathbb{Z}$ be finite with $|H| = n$. Take
any $x \in H$ and write it as $x = a/b + \mathbb{Z}$ in lowest terms, so
$x$ has order $b$ by (a). By Lagrange's theorem applied in the finite group
$H$, the order of $x$ divides $|H|$: $b \mid n$. Writing $n = bd$,
$$x = \frac{a}{b} + \mathbb{Z} = \frac{ad}{n} + \mathbb{Z} \in H_n .$$
Thus $H \subseteq H_n$. But $|H| = n = |H_n|$ by (c), and a subset of a
finite set with the same number of elements is the whole set: $H = H_n$.

Consequently a subgroup of order $n$ exists ($H_n$) and any subgroup of
order $n$ equals $H_n$ — uniqueness — and $H_n$ is cyclic by construction.

**(e)** Let $H = \langle x_1, \dots, x_m \rangle$ with
$x_i = a_i/b_i + \mathbb{Z}$ in lowest terms, and put
$n = \operatorname{lcm}(b_1, \dots, b_m)$. Each generator satisfies
$b_i \mid n$, so $x_i \in H_{b_i} \subseteq H_n$ by (c). A subgroup
containing all the generators contains everything they generate, hence
$H \subseteq H_n$ and $|H| \leq n$: $H$ is finite. Being a subgroup of the
cyclic group $H_n$, it is moreover cyclic.

In particular a single element generates a finite subgroup, while
$\mathbb{Q}/\mathbb{Z}$ is infinite by (b) — so no single element
generates it, and $\mathbb{Q}/\mathbb{Z}$ is not cyclic. (Every finitely
generated subgroup is cyclic, yet the group itself is not: cyclicity is
not a "local" property.)
