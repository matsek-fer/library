# Closure operator

Let $(P, \le)$ be a partially ordered set.

**Definition.** A map $c \colon P \to P$ is a **closure operator** if for
all $p, p' \in P$:

1. **extensive**: $p \le c(p)$ — closing never moves you down;
2. **monotone**: $p \le p' \implies c(p) \le c(p')$ — closing respects
   the order;
3. **idempotent**: $c(c(p)) = c(p)$ — closing twice is closing once.

An element $p$ with $c(p) = p$ is called **closed**; the closed elements
are exactly the fixed points of $c$, and by idempotence also exactly the
elements of the image $c(P)$.

The three axioms say together that $c(p)$ behaves like "the smallest
closed element above $p$": extensivity puts it above $p$, idempotence
makes it closed, and monotonicity makes the assignment order-coherent.
Indeed, if $q$ is closed and $p \le q$, then $c(p) \le c(q) = q$ — so
$c(p)$ really is below every closed element above $p$.

Familiar instances, all in posets ordered by inclusion: the topological
closure $\overline{A}$ of a subset of a space; the subgroup
$\langle S \rangle$ generated by a subset of a group; the span of a set
of vectors; the ideal generated by a subset of a ring; the set of
logical consequences of a set of axioms. None of these is closed under
the others' operations, yet every one of them obeys these three lines —
and each arises from a Galois connection
([[thm-connection-induces-closure]],
[[exm-generated-subgroup-closure]]).

A word on the dual, which is a genuinely different animal: a map
satisfying $c(p) \le p$ together with monotonicity and idempotence is an
**interior** (or kernel) operator — the topological interior is the
model.
